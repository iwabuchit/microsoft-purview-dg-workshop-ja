U01.ガバナンス ドメインとビジネスの概念の作成(Salesドメイン)

はじめに

📢 導入

このモジュールでは、Microsoft Purview を活用して、Sales部門向けのガバナンス ドメインとビジネス用語の定義を行う方法を学びます。データガバナンスの基盤となるドメインの作成から、用語や重要なデータ要素の定義、データ製品の構築、アクセスポリシーの設定まで、実践的なステップを通じて理解を深めます。

🤔 前提条件

  • D04. データ資産のキュレーション

🎯 ゴール

  • Sales部門向けのガバナンス ドメインを新規作成する
  • ビジネス用語と重要なデータ要素を定義し、関連付ける
  • EC取引データを統合したデータ製品を作成する
  • データ製品に対するアクセスポリシーを設定し、利用目的と許諾情報を構成する

Note

  • 操作対象ソリューションは統合カタログです。
  • このモジュールでは主にSalesドメインの管理者が操作をします。

ロールの付与

このセクションはデータ ガバナンス管理者が操作をします。

  1. 設定から統合カタログのRoles and permissionsを選択しガバナンス ドメイン作成者をクリックします。

  2. Salesドメインの管理者とMarketingドメインの管理者を追加します。

  3. 次にグローバル カタログ リーダーをクリックします。

  4. Salesドメインの管理者とMarketingドメインの管理者を追加します。

Sales部門用のガバナンス ドメイン作成

このセクション以降はSalesドメインの管理者が操作をします。

  1. ガバナンス ドメインから新しいガバナンス ドメインを選択します。

  2. 名前、説明を入力し種類から業種を選択し作成します。

    名前

    ワークショップ用Salesドメイン

    説明

    Sales部門用のガバナンス ドメイン。

    Info

    種類は、ガバナンス ドメインの目的を示す追加記述子です。以下の種類が選択できますが種類による動作の違いはありません。

    • 機能単位(Functional unit)
    • 業種(line of business)
    • データドメイン(data domain)
    • 規制(regulatory)
    • プロジェクト(project)

  3. 次の画面のようにガバナンス ドメインが作成されます。

  4. ガバナンス ドメインを公開します。

用語の作成

  1. 用語集の用語から全て表示をクリックします。

  2. 新しい用語をクリックします。

  3. 次の情報を入力し次へをクリックします。

    名前

    Eコマース取引

    説明

    オンラインプラットフォーム上で行われた商品の購入・販売に関する取引データ。国別に分かれており、グローバルな購買傾向の分析に活用可能。

    所有者

    Sales部門の管理者

  4. 次へをクリックします。

  5. 作成をクリックします。

  6. 用語が作成されたことを確認し公開します。

  7. 同じ要領で用語をもう一つ作成します。

    名前

    支払い方法

    説明

    クレジットカード、PayPal、銀行振込など、取引に使用された決済手段。

    所有者

    Sales部門の管理者

  8. 用語が作成されたら、関連から用語の追加をクリックし関連を選択します。

  9. 前に作成した用語をチェックし追加します。

  10. 関連が設定されたら公開します。

重要なデータ要素の作成

  1. 重要なデータ要素から全て表示をクリックします。

  2. 新しい重要なデータ要素をクリックします。

  3. 次の情報を入力して作成します。

    名前

    取引金額

    説明

    各取引の金額情報。通貨単位はシステム依存で、売上集計や平均購入額の算出に使用される。

    所有者

    Sales部門の管理者

    必要なデータ型

    数値

  4. 重要なデータ要素に列を追加します。

  5. ecommerce_transactions_germany.parquet を選択します。

  6. Purchase_Amount 列を選択します。

  7. 同じ要領で ecommerce_transactions_japan.parquet と ecommerce_transactions_usa.parquet の Purchase_Amount 列を追加し公開します。

データ製品の作成

  1. データ製品から全て表示をクリックします。

  2. 次の情報を入力して作成します。

    名前

    ECサイトのトランザクションデータセット

    説明

    このデータ製品は、ドイツ、日本、アメリカにおけるEコマース取引情報を統合したものであり、以下の3つのParquetファイルで構成されています。

ecommerce_transactions_germany.parquet
ecommerce_transactions_japan.parquet
ecommerce_transactions_usa.parquet

    種類

    データセット

    対象ユーザー

    データエンジニア

    所有者

    Sales部門の管理者

    Info

    種類は、データ製品を使用するユーザーがその種類を識別するために設定し検索でデータ製品をフィルターするために使用できます。

  3. ユースケースに次の文章を入力し作成します。

    各ファイルには、ユーザーの属性情報と取引に関する詳細が含まれており、グローバルな購買行動の分析や、国別のマーケティング施策の立案に活用できます。

  4. データ資産の追加を選択し完了をクリックします。

  5. 3つのファイルをチェックし追加をクリックします。

  6. 用語集の用語から追加をクリックします。

  7. 2つの用語をチェックし追加します。

データ製品のアクセスポリシー設定

  1. ポリシー管理をクリックします。

  2. 目的の追加をクリックし追加の利用目的を入力します。

    名前

    説明

    機械学習モデルのトレーニング

    購買予測やレコメンデーションなどのモデル構築

    品質・異常検知

    不正取引や異常な購買パターンの検出など、データ品質やセキュリティの観点での分析に使用するため。

    データアクセスの制限を3 Months に設定します。

    次の値を入力し構成証明の追加をクリックし利用許諾書の情報を入力します。

    アクセス要求の承認者

    Sales部門の管理者

    データ アクセス プロバイダー

    Sales部門の管理者

    データ コピーを許可する

    ✅

    表示名

    ECデータ利用許諾書

    ファイルの場所

    https://iwabuchit.github.io/microsoft-purview-dg-workshop-ja/3.Unified%20Catalog/docs/kyodaku.docx

    要求フォームのプレビューを確認し変更を保存します。

  3. 全ての情報を入力したら公開します。
