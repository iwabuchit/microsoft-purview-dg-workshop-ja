D02. Azure Data Lake Storage Gen2の登録とスキャン

はじめに

📢 導入

このモジュールでは、Microsoft Purview を活用して Azure Data Lake Storage Gen2 をデータマップに登録し、スキャンを実施する手順を学びます。Sales ドメインの管理者を操作主体とし、適切なロールの付与からストレージの登録、スキャンの実行までを体系的に解説します。データ資産の可視化と管理を効率化するための基本操作を習得することが目的です。

🤔 前提条件

  • D01.テクニカル ドメインとコレクションの作成

🎯 ゴール

  • Azure Data Lake Storage Gen2をコレクションに登録しスキャンを行う

Note

  • 操作対象ソリューションはデータマップです。
  • このモジュールではSalesドメインの管理者が操作をします。

PurviewアカウントのマネージドIDへのロール付与

  1. ストレージアカウントのアクセス制御から追加を選択し、ロールの割り当て追加をクリックします。

  2. ストレージ Blob データ閲覧者を選択します。

  3. アクセスの割当先を選択しロールを付与します。

    メンバーに Purview アカウントのマネージドID を追加します。

    メンバーに Salesドメイン管理者 を選択します。

Azure Data Lake Storage Gen2の登録

  1. Purview アカウントのポータルへアクセスします。

    https://purview.microsoft.com/

  2. データマップ を選択します。

  3. データソース から Salesコレクション の 登録アイコン をクリックします。

  4. Azure をクリックし Azure Data Lake Storage Gen2 を選択し続行します。

  5. ストレージアカウント の情報を入力、データポリシーの適用 を オフ にして登録します。

Azure Data Lake Storage Gen2のスキャン

  1. スキャンアイコン をクリックします。

  2. スキャン名を入力し 接続のテスト をクリック、テストが成功したら続行します。

  3. スキャン対象を確認して続行します。

  4. 既定のスキャン ルール セットを選択して続行します。

  5. 一度だけを選択し続行します。

  6. スキャンの内容を確認し保存して実行をクリックします。

  7. 詳細の表示をクリックします。

  8. 正常にスキャンが行われるとスキャンの状態が完了済みになります。

    Note

    • 正常にスキャンが行われると次のファイルが登録されます。
      • ecommerce_transactions_germany.parquet
      • ecommerce_transactions_japan.parquet
      • ecommerce_transactions_usa.parquet
